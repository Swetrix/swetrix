To use Swetrix on your website, you need to add a tracking script to your website and there are several ways to do this.

<Callout type="info" title="Using a CMS or site builder?">

If your website runs on WordPress, Wix, Shopify, Webflow, or another CMS/site builder, use a dedicated integration guide instead of editing HTML manually.

See [CMS & website builder integrations](/integrations#cms--website-builders).

</Callout>

<TabsContent value="managed">

Open **Project settings → Tracking script**, copy your project's tag, and paste it in the shared `<head>` of your site. Swetrix Cloud uses the following tag.

```html
<script defer crossorigin="anonymous" src="https://swetrix.com/p/YOUR_PROJECT_ID.js"></script>
```

Community Edition serves the tracker and the replay recorder from your own instance. Use the URL shown in your project settings.

| Section             | What you can turn on                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Core tracking       | Pageviews are on by default. Browser error tracking is optional.                                                    |
| Auto-capture events | Count clicks on links that lead to other sites.                                                                     |
| Session replay      | Enable recording with total masking. The recorder downloads only when recording is enabled for an eligible visitor. |

Saved changes take effect on new page loads within five minutes. If your site asks for consent, configure your consent manager to load the tag after the visitor agrees. Use the manual script when you need to start and stop replay separately from analytics.

When migrating, replace the old script tag and its automatic tracking calls with the managed tag. Check any custom events or identity calls run after the tag has loaded. Remove the old `<noscript>` pixel if you want the pageviews switch to control all pageview collection.

For a Content Security Policy, allow `https://swetrix.com` in `script-src` and `https://api.swetrix.com` in `connect-src` on Cloud. On Community Edition allow your instance's origin in both directives.

</TabsContent>
<TabsContent value="html">

The easiest way to add the tracking script to your website is to edit the HTML code of your website.
To do this, paste the following code snippet into the Body section (`<body>` tag). You have to place the script within the `<body>...</body>` tags.

```html
<script src="https://swetrix.org/swetrix.js" defer></script>
<script>
  document.addEventListener("DOMContentLoaded", function () {
    swetrix.init("YOUR_PROJECT_ID");
    swetrix.trackViews();
  });
</script>

<noscript>
  <img
    src="https://api.swetrix.com/log/noscript?pid=YOUR_PROJECT_ID"
    alt=""
    referrerpolicy="no-referrer-when-downgrade"
  />
</noscript>
```

<Callout type="warn">
It's important to remember to replace `YOUR_PROJECT_ID` with your actual Project ID, which you can find in the Dashboard, otherwise tracking will not work!

</Callout>

Done. Now you can start using Swetrix on your website.

To record session replays, start the recorder from your site code after initialising Swetrix. The replay recorder is loaded asynchronously only when you preload or start it. See [`startSessionReplay()`](/swetrix-js-reference#startsessionreplay) for setup and privacy options.

</TabsContent>
<TabsContent value="npm">

If you are using a website based on a JavaScript framework such as React or Vue, you can install Swetrix via npm and use it on your website.

<Steps>
<Step>
### Install the package

```bash
npm install swetrix
```

</Step>
<Step>
### Import Swetrix

Import the module into your project's root file (in React this is usually called `index.js` or `App.js`, and these files are located in the `src` folder):

```js
import * as Swetrix from "swetrix";
```

</Step>
<Step>
### Start tracking

After that you can track anything you want. For example, the following code snippet will work just fine:

```js
Swetrix.init("YOUR_PROJECT_ID");
Swetrix.trackViews();
```

To record session replays, call `Swetrix.startSessionReplay()` after `Swetrix.init()`. The npm package dynamically imports the installed replay recorder only when you preload or start it. See [`startSessionReplay()`](/swetrix-js-reference#startsessionreplay) for setup and privacy options.

</Step>
</Steps>

</TabsContent>
